Todas las fórmulas utilizadas en las tarjetas y visualizaciones explicadas paso a paso.

// 1. TARJETA: TOTAL HISTÓRICO Y CRECIMIENTO MENSUAL (MoM)

Calcula el volumen total y la variación porcentual con respecto al mes anterior usando inteligencia temporal:

Total Solicitudes = COUNTROWS('Fact_Solicitudes_Lists')

Solicitudes MoM % =
VAR MesActual = [Total Solicitudes]
VAR MesAnterior = CALCULATE([Total Solicitudes], DATEADD('Dim_Calendario'[Date], -1, MONTH))
RETURN
DIVIDE(MesActual - MesAnterior, MesAnterior, 0)

// 2. TARJETA: CUMPLIMIENTO GLOBAL DE SLA (%)

Porcentaje de tickets completados dentro del tiempo límite estipulado:

SLA Compliance % =
DIVIDE(
  CALCULATE([Total Solicitudes], 'Fact_Solicitudes_Lists'[Cumple_SLA] = TRUE(), 'Fact_Solicitudes_Lists'[Estado] = "Completada"),
  CALCULATE([Total Solicitudes], 'Fact_Solicitudes_Lists'[Estado] = "Completada"),
  0
)

// 3. TARJETA: TIEMPO MEDIO DE RESOLUCIÓN (MTTR EN DÍAS)

Promedio de días transcurridos desde que se aprueba el requerimiento en Lists hasta su cierre efectivo:

MTTR (Dias) =
AVERAGEX(
  FILTER('Fact_Solicitudes_Lists', NOT(ISBLANK('Fact_Solicitudes_Lists'[Fecha_Cierre]))),
  DATEDIFF('Fact_Solicitudes_Lists'[Fecha_Aprobacion], 'Fact_Solicitudes_Lists'[Fecha_Cierre], DAY)
)

// 4. TARJETA: TASA DE SOLICITUDES BLOQUEADAS (%)

Mide el cuello de botella: porcentaje de solicitudes detenidas por dependencias sobre el volumen total:

Blocked Rate % =
DIVIDE(
  CALCULATE([Total Solicitudes], 'Fact_Solicitudes_Lists'[Estado] = "Bloqueada"),
  [Total Solicitudes],
  0
)

// 5. TARJETA: CARGA ACTIVA EN CURSO (WORK IN PROGRESS)

Volumen neto de trabajo que está consumiendo capacidad de los equipos actualmente:

Active Workload =
CALCULATE(
  [Total Solicitudes],
  'Fact_Solicitudes_Lists'[Estado] IN { "Backlog", "En Curso" }
)

// Generación de Dim_Calendario para series de tiempo, inteligencia temporal y gráficos de evolución

Dim_Calendario =
VAR MinDate = MIN('Fact_Solicitudes_Lists'[Fecha_Ingreso])
VAR MaxDate = TODAY()
RETURN
ADDCOLUMNS(
  CALENDAR(MinDate, MaxDate),
  "Año", YEAR([Date]),
  "Mes_Nro", MONTH([Date]),
  "Mes_Nombre", FORMAT([Date], "MMMM"),
  "Año_Mes", FORMAT([Date], "YYYY-MM"),
  "Trimestre", "T" & FORMAT([Date], "Q")
)

* Buena práctica: Se marca formalmente como "Tabla de Fechas" (Mark as Date Table) para habilitar funciones DAX como DATEADD y SAMEPERIODLASTYEAR.

-- Extracción analítica y cálculo de cumplimiento de SLA en motor relacional

SELECT
  s.servicio,
  s.segmento,
  COUNT(s.ticket_id) AS total_solicitudes,
  ROUND(AVG(DATEDIFF(day, s.fecha_aprobacion, s.fecha_cierre)), 1) AS mttr_dias,
  ROUND(100.0 * SUM(CASE WHEN s.cumple_sla = 1 THEN 1 ELSE 0 END) / NULLIF(COUNT(s.ticket_id), 0), 2) AS pct_sla_compliance
FROM fact_solicitudes_lists s
WHERE s.estado = 'Completada'
GROUP BY s.servicio, s.segmento
ORDER BY total_solicitudes DESC;
